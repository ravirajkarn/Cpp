# Search in Rotated Sorted Array

This repository contains a robust, modern C++ solution for the classic LeetCode problem: [Search in Rotated Sorted Array](https://leetcode.com/problems/search-in-rotated-sorted-array/description/). 

The project demonstrates problem-solving progression by featuring two distinct algorithmic approaches, fully supported by comprehensive unit testing and modern C++ build tools.

## 🚀 Overview

This project implements an `O(log n)` time complexity search algorithm to find a target value in an array that was originally sorted in ascending order but has been rotated at an unknown pivot. 

### Implementations Included
- **Original Logic (`me::rotatedArray`)**: An authentic, independently developed approach that identifies the sorted segment and uses a helper binary search function.
- **Optimized Logic (`google::rotatedArray`)**: A refined, industry-standard, single-pass binary search algorithm that handles all edge cases cleanly without the need for a secondary helper function.

## 🛠 Project Structure

- **`inc/search_in_rotated_sorted_array.hpp`**: The core header containing both the `me` and `google` namespaces with their respective search implementations.
- **`src/leetcode.cpp`**: The main execution entry point demonstrating the algorithm.
- **`test/leetCode_test.cpp`**: Google Test suite specifically validating the author's original algorithm (`me` namespace) against numerous edge cases.
- **`test/google_test.cpp`**: Google Test suite validating the optimized algorithm (`google` namespace).
- **`CMakeLists.txt` & `conanfile.py`**: Configuration files for building the project and managing dependencies.

## ⚙️ Dependencies

This project relies on modern C++ tooling:

## 🏗️ Build Instructions

1. **Clone the repository:**
```bash
   git clone https://github.com/ravirajkarn/Cpp.git
   cd "Cpp/LeetCode/33 Search in Rotated Sorted Array"
```

2. Install dependencies via Conan and generate CMake configurations:

```Bash
conan install . --build=missing -s build_type=Release
```
Configure the project with CMake:
```Bash
# Use the toolchain file generated by Conan
cmake -G "Ninja" -S . -B build/Release -DCMAKE_BUILD_TYPE=Release -DCMAKE_TOOLCHAIN_FILE=generators/conan_toolchain.cmake
```
(Note: The exact path to conan_toolchain.cmake may vary slightly based on your Conan layout configuration).

Build the project:

```Bash
cmake --build build/Release
```

## 🧪 Testing
The project includes extensive test coverage, validating scenarios such as:

- Empty arrays and single elements.

- Two-element arrays (rotated and unrotated).
- Targets residing on the left, right, peak, or valley of the pivot.

- Completely missing targets.

- Standard arrays rotated by one or perfectly unrotated arrays.

To run the unit tests, execute the generated binaries inside your build directory:

```Bash
# Run tests for the optimized logic
./build/Release/google_test

# Run tests for the original logic
./build/Release/leetCode_test
```
Alternatively, you can run all discovered tests using CTest:

```Bash
cmake --build build/Release --target test
```
